# 문서 편집 페이지

## 대상 사용자

- 처음에는 나 혼자 사용합니다.
- 이후 지인과 불특정 다수가 쓸 수 있도록 인터넷 공개 주소로 올릴 계획입니다.

## 사용 목적

- 문서의 확장자 변환, 같은 확장자 문서의 병합, 나누기 같은 문서 단위 편집을 한 곳에서 합니다.
- 기능 우선순위는 확장자 변환, 병합, 나누기 순서입니다.
- 다루고 싶은 확장자는 pdf, docx, doc, txt, hwp, hwpx, ppt, pptx, webp, png, jpg, gif입니다.
- 1차에서 꼭 되어야 하는 기능은 pdf 병합·나누기, hwp → pdf, hwpx → hwp, pdf → hwp입니다.
- 만드는 순서는 쉬운 기능(pdf 병합·나누기, hwp → pdf, hwpx → hwp)을 먼저 만들고, pdf → hwp는 마지막에 만들었습니다.

## 화면 구성과 동작

- 한 화면 구조입니다. 파일을 끌어다 놓거나 "파일 고르기"를 눌러 올리면, 그 파일로 할 수 있는 작업이 자동으로 표시됩니다.
- 파일을 올리기 전 첫 화면입니다.
  - 제목 옆에 "? 도움말" 버튼이 있고, 누르면 사용 방법(파일 올리기, 작업 고르기, 내려받기)이 열립니다.
  - "1 파일 올리기 → 2 작업 고르기 → 3 내려받기" 3단계 안내가 있습니다.
  - 큰 업로드 그림, "여기에 파일을 끌어다 놓으세요" 문구, "파일 고르기" 버튼이 있는 업로드 박스가 있습니다.
  - 업로드 박스 아래에 할 수 있는 작업 카드(PDF 합치기, PDF 나누기, HWP → PDF, HWPX → HWP, PDF → HWP)가 있고, 카드를 누르면 파일 선택창이 열립니다.
- 파일을 올린 뒤 화면입니다.
  - 3단계 안내와 작업 카드는 사라지고, 업로드 박스는 한 줄로 작아집니다.
  - 왼쪽 "올린 파일" 목록에 형식, 이름, 크기가 표시됩니다. 끌어서 또는 ↑↓ 버튼으로 순서를 바꾸고, ✕로 하나씩 빼고, "모두 지우기"로 비웁니다.
  - 오른쪽 "할 수 있는 작업"에 "이제 할 작업을 골라 주세요" 안내와 함께, 올린 파일에 맞는 작업만 표시됩니다.
- 작업별 동작입니다.
  - PDF 병합: PDF가 2개 이상일 때 "합치기"를 누르면 목록 순서대로 합쳐 "병합.pdf"를 만듭니다. PDF가 아닌 파일은 합치지 않습니다.
  - PDF 나누기: 쪽 번호를 눌러 고르거나 "1-3, 5, 8-10"처럼 범위를 입력해 "적용"합니다. "전체 선택", "선택 해제", 선택된 쪽 수 표시가 있고, PDF가 여러 개면 나눌 PDF를 목록에서 고릅니다. "나누기"를 누르면 고른 쪽만 모은 새 PDF 하나("파일이름_선택쪽.pdf")를 만듭니다.
  - HWP → PDF: "PDF로 변환"을 누르면 쪽을 그림으로 바꿔 PDF에 넣습니다.
  - HWPX → HWP: "HWP로 변환"을 누르면 HWP 파일을 만듭니다.
  - PDF → HWP: "HWP로 변환"을 누르면 PDF의 글자와 도형을 읽어 HWP 문서를 만듭니다.
  - 위에 없는 형식(docx, doc, txt, ppt, pptx, webp, png, jpg, gif)은 "지원하지 않는 형식"으로 표시됩니다.
- 작업이 끝나면 "3 완성됐어요. 내려받기를 눌러 저장하세요." 안내와 초록색 내려받기 버튼이 나타나고, 버튼을 눌러야 저장됩니다. 자동으로 저장되지 않습니다. 파일을 여러 개 변환하면 파일마다 버튼이 나옵니다.
- 오류가 나면 쉬운 말로 알리고 "이렇게 해 보세요" 해결 방법을 함께 보여줍니다.
- 한 번에 다루는 파일은 최대 10개입니다. 10개를 넘는 파일은 추가되지 않고 안내 문구가 나옵니다. (제한이 없으면 더 좋지만, 필요하면 10개까지로 정했습니다.)
- 파일은 브라우저 안에서만 처리하고 서버로 보내지 않습니다.
- 더블클릭하면 브라우저에서 열리는 HTML 파일 하나로 실행합니다.
- 디자인은 난잡하지 않고 깔끔한 파란 계열이며, 글자와 버튼을 크게 했습니다. 내려받기 버튼만 초록색입니다.
- (미정: 로고, 참고할 사이트. 지금은 참고 자료가 없습니다.)

## 필요한 자료

- 변환 확인에 쓸 실제 hwp 파일 5개 (테스트에 사용할 샘플 파일 필요)
- 병합 확인에 쓸 pdf 파일 10개 (테스트에 사용할 샘플 파일 필요)
- 변환 엔진 rhwp(WASM)와 PDF 처리 라이브러리 pdf-lib: 둘 다 HTML 파일 안에 들어 있습니다.
- 디자인 자료(로고, 색상): 없음
- 사용 환경: 맥. 한컴오피스가 설치된 윈도우 PC도 있습니다.

## 완료 기준

1차 완료 기준입니다.

- 가진 실제 hwp 파일 5개를 pdf로 바꿨을 때, 5개 모두 hwp로 볼 때와 차이 없이 같아야 합니다.
- hwpx → hwp 변환도 5개 중 5개가 변환 전과 차이 없이 같아야 합니다.
- pdf → hwp 변환은 5개 중 5개가 완전히 같아야 합니다.
- pdf 10개를 원하는 순서대로 병합할 수 있어야 합니다.
- (미정: pdf에서 쪽을 골라 나눈 결과가 어떠해야 합격인지)
- 꼭 지켜야 할 조건: 로그인 없이 쓸 수 있고, 외부 파일이나 서버 없이 HTML 파일 하나를 더블클릭하면 브라우저에서 열립니다. 파일은 브라우저 안에서만 처리합니다.

## 추가 기능

2차에서 구현할 기능입니다.

- 구글 계정으로 로그인 (나중에 이메일 가입도 함께 지원할 의향)
- 변환 기록 저장: 파일 이름, 변환 종류, 날짜 내역과 결과 파일을 다시 내려받을 수 있게 계정에 저장하며, 계정당 5GB로 제한
- 나머지 확장자(docx, doc, txt, ppt, pptx, webp, png, jpg, gif 등) 지원
- 인터넷 공개 주소로 공개 (서버 비용은 웬만하면 무료)
- (미정: 저장된 파일의 보관 기간)

## 한계 및 비목표

(최종 HTML 기준으로 수정했습니다)

1. 1차에는 로그인과 변환 기록 저장이 없습니다.
2. 1차에서는 pdf 병합·나누기, hwp → pdf, hwpx → hwp, pdf → hwp만 지원하고, hwp → hwpx와 나머지 확장자 변환은 2차로 미룹니다.
3. pdf 나누기는 고른 쪽을 새 PDF 하나로 만드는 것까지만 하고, 나머지 쪽을 따로 저장하는 기능은 없습니다.
4. hwp → pdf는 쪽을 그림으로 바꿔 넣기 때문에 PDF 안의 글자를 선택하거나 검색할 수 없습니다. 한글 글꼴이 없는 컴퓨터에서는 원본과 모양이 달라질 수 있습니다. (확인 필요: 실제 파일로 비교해 봐야 합니다.)
5. 암호가 걸렸거나 손상된 PDF는 처리하지 못하고 안내 문구를 보여줍니다.
6. 엔진이 들어 있어 HTML 파일이 약 14MB이고, 변환을 처음 할 때 엔진을 준비하는 데 몇 초 걸립니다.
7. 지금은 내 컴퓨터(맥)에서만 사용하고, 인터넷 공개는 2차에서 합니다. 휴대폰 화면은 따로 고려하지 않았습니다.
8. (확인 필요: pdf → hwp는 글자와 표를 읽어 hwp 문서로 다시 만드는 방식이라 "완전히 같음" 기준을 못 넘을 수 있습니다. 못 넘을 때의 처리 방식은 미정입니다.)
9. (미정: 파일 하나의 크기 제한)

## 검증 방법

(최종 HTML 기준으로 수정했습니다)

- hwp → pdf, hwpx → hwp, pdf → hwp: 각각 실제 파일 5개를 변환한 뒤, 변환 전과 변환 후의 모습을 비교해 차이가 없는지 확인합니다. (5개 비교 결과는 아직 기록하지 않았습니다.)
- pdf 병합: pdf 10개를 원하는 순서로 병합한 뒤, 결과 pdf의 쪽 순서가 정한 순서와 같은지 확인합니다.
- (미정: pdf 나누기의 검증 방법)
- 사용자 재테스트: 나윤석 님이 수정본으로 같은 작업을 다시 해보고, 첫 버튼을 찾는 데 걸린 시간과 새로 나온 질문을 기록합니다. (재테스트 전입니다.)
