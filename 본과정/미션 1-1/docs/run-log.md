# 3. 실행 로그

## 작업 기록
1. **과업 및 출력 규격 정의:** 아이스크림 전문점 근무 교대 인수인계 일지 정리를 과업으로 선정하고, `[긴급]`, `[중요]`, `[공지]` 고정 헤더와 `[완료]`, `[보류]`, `[지연]` 상태 판별 규격을 정의함.
2. **모델 3종 비교 및 선정:** `Gemini Hydrogen`, `Sonnet 5.5`, `GPT-5.6 Luna`에 동일한 테스트 프롬프트를 입력해 4가지 기준(100점 만점)으로 채점한 결과, 95점을 기록한 `GPT-5.6 Luna`를 최종 선정함.
3. **시스템 프롬프트 v1 설계 및 실전 대화 수행:** 페르소나(매장 운영 서기)와 Few-shot 예시 3건을 포함한 시스템 프롬프트 v1을 적용해 총 12턴 대화를 수행함.
4. **조건 변경 및 동일 입력 반복 검증:** 7턴째에 픽업 시간 변경(19:00 → 20:30)과 시스템 점검 조건을 부여하고, 11·13턴에서 동일 질문을 반복해 답변 일관성과 환각 여부를 검증함.
5. **로그 지점 표시 및 v2 개선 도출:** 대화 원문 검토 결과 사실 오류(환각)는 0건이었으나, 8턴째 응답에서 `[완료]` 대신 대괄호 누락 및 지시문에 없는 `진행 예정` 라벨·부연 요약 섹션이 추가된 규칙 이탈 지점을 포착해 프롬프트 v2 개선 근거로 기록함.
